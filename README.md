# ✈️ Трекер самолётов (Aeroplane Tracker)

Курсовая работа по программированию на Python. Программа представляет собой интеграцию с внешними API для получения информации о самолётах, находящихся в воздушном пространстве выбранной страны, с возможностью фильтрации, сортировки и сохранения данных в локальное хранилище.

## 📝 Описание проекта
Проект реализован в парадигме ООП и включает в себя:
*   Интеграцию с **Nominatim (OpenStreetMap)** для получения географических координат (bounding box) страны.
*   Интеграцию с **OpenSky Network API** для получения данных о самолетах в заданном регионе.
*   Валидацию и инкапсуляцию данных о самолетах (позывной, страна, скорость, высота).
*   Сохранение полученных данных в JSON-файл.
*   Интерактивный консольный интерфейс для фильтрации, сортировки и вывода топа самолетов.

## 🛠️ Стек технологий
*   **Python 3.13+**
*   **requests** — для работы с API.
*   **pytest**, **pytest-cov** — для тестирования и оценки покрытия кода.

# 🎮 Пример работы
При запуске программа попросит ввести данные:

Введите название страны: Spain

Введите количество самолетов для вывода в топ N: 5

Введите названия стран для фильтрации по стране регистрации: France Germany (или пропустите, нажав Enter)

Введите диапазон высот полета: 0 - 15000

Программа выведет отфильтрованный и отсортированный по убыванию высоты список самолетов, а также сохранит все полученные данные в файл data/aeroplanes.json
